Paper [AIAA]: Uncovering Hazards using Multi-Objective Optimization

For the paper Girshfeld, I., Hulse, D., & Irshad, L. (2023). Uncovering Hazards Using a Multi-Objective Optimization to Explore the Faulty State-Space. In AIAA SCITECH 2023 Forum (p. 2578).

The goal of this notebook is to demonstrate the performance of evolutionary search methods on the hazard elicitation problem. The methods to compare are:

  • monte_carlo (a random search)

  • evolutionary algorithm

  • cooperative coevolutionary algorithm

These methods have been coded up using the deap simulation package in search_rover.py.

from search_rover import *
import pandas as pd

An experiment can be run calling the following methods:

result_mc, sol_mc= montecarlo(ngen=50, weight=0.5, filename='outputs_paper_aiaa_coevolution/rslt_random.csv')
result_ea, sol_ea= ea(ngen=50, weight=0.5, filename='outputs_paper_aiaa_coevolution/rslt_ea.csv')
result_ccea, sol_ccea, pop= ccea(ngen=50, weight=0.5, filename="outputs_paper_aiaa_coevolution/rslt_ccea.csv")
